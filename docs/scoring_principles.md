# Scoring Principles

The scoring system should remain conservative.

## Deterministic
These should not rely on AI:
- purchase price conversion
- landed cost
- expected profit
- margin
- recommended max bid
- threshold checks

## AI-Assisted
AI may help with:
- title normalization
- trim detection
- option extraction
- risk flag detection
- comparable explanation
- seller message generation
- Swedish resale ad text

## Core Scores
- profit_score
- confidence_score
- risk_score
- liquidity_score
- final_deal_grade

## Important
AI should explain uncertainty, not hide it.
