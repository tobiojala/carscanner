# Project Vision

Car Arbitrage Scanner is a private internal tool for identifying profitable car import opportunities from Germany to Sweden.

The product helps the owner:
- find interesting German listings
- compare them with Swedish resale listings
- estimate landed cost
- estimate expected resale value
- calculate conservative profit
- score risk and confidence
- track deals from research to sale

The real value is not scraping. The real value is:
- pricing intelligence
- model research
- Swedish market knowledge
- risk scoring
- import cost assumptions
- real outcome tracking
